# Enterprise IT Homelab Project

## Overview
A hands-on homelab environment built on Proxmox VE, 
covering Linux administration, Windows Server, 
Kubernetes, infrastructure monitoring, and cloud 
integration with AWS and Azure.

## Environment
- **Hypervisor:** Proxmox VE 9.1.1
- **Hardware:** Dell PowerEdge Server
- **VMs:** Ubuntu 24.04 LTS, Windows Server 2022

## Lab Structure
| Phase | Topic | Status |
|---|---|---|
| Phase 1 | Linux Hardening | ✅ In Progress |
| Phase 2 | Windows Server (AD, DNS, DHCP) | ⏳ Upcoming |
| Phase 3 | Kubernetes & Docker | ⏳ Upcoming |
| Phase 4 | Grafana & Prometheus Monitoring | ⏳ Upcoming |
| Phase 5 | Backup & Disaster Recovery | ⏳ Upcoming |
| Phase 6 | Cloud Integration (AWS & Azure) | ⏳ Upcoming |

## Skills Demonstrated
- Linux system administration & security hardening
- Windows Server administration & Active Directory
- Container orchestration with Kubernetes (K3s)
- Infrastructure monitoring with Grafana & Prometheus
- Cloud infrastructure on AWS and Azure
- Documentation & SOP writing
